# Portfolio

## Local Development

1. Install dependencies:

```bash
npm install
```

2. Start the local dev server:

```bash
npm run dev
```

3. Open the URL printed in the terminal, usually `http://localhost:8080`.

## Build

Create a production build with:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deploy

This project is configured for GitHub Pages deployment.

```bash
npm run deploy
```

That command runs a production build first and then publishes the `dist` folder with `gh-pages`.
